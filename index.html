Cybersecurity / Identity Security / Infrastructure

Self-Hosted Password Manager & Automated Disaster Recovery

While operating VNTheJeweler, I identified a cybersecurity concern involving password reuse across multiple business accounts. Recognizing that reused credentials could increase the impact of a single compromised password, I designed and deployed a self-hosted password management solution to address the issue.

Implemented Vaultwarden on a Raspberry Pi 5 using Docker, with secure remote accessibility through Cloudflare Tunnel and additional account protection through two-factor authentication.

Developed an automated disaster recovery workflow using Restic, Rclone, and Google Drive to maintain encrypted off-site backups. Integrated systemd scheduling, backup retention policies, automatic retry functionality, and Healthchecks.io monitoring.

Validated backup recovery by restoring an encrypted snapshot and verifying SQLite database integrity.

Pi-hole DNS Filtering & Secure Remote Access

Deployed a containerized Pi-hole DNS filtering service on a Raspberry Pi 5 to provide centralized DNS management, advertisement blocking, and network-level filtering of unwanted domains.

Configured Docker networking, persistent storage, Linux firewall rules, and VPN client configurations. Validated functionality through DNS query monitoring, custom domain blocking tests, and WireGuard connectivity verification.
